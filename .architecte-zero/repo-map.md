# Repository map
- `src/engine/`: renderer-independent Mage card AST, validation, generation, history, and persistence.
- `src/extension/`: MV3 host, service worker, content messaging, and side-panel boundary.
- `src/broker/` and `src/contracts/`: run transport, receipts, authentication bindings, and admission.
- `src/components/`: host-neutral presentation owned through typed props and events.
